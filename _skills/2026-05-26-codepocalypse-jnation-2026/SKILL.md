## Areas for Improvement (Dimension 14)

1. `shortchanged` (severity: warning) - the recurring corpus-top issue, and it lands on the most persuasive material. 'time time time time time' at 38:23, 'We have 4 minutes and we are not done yet' at 43:21, and the eval payoff - 'four times better' vs '25% correct', the whole business case for the Tessl skills - gets about fifteen seconds before 'We need to stop' at 47:12. Round 4's LangChain4j topology and the observability pass are narrated at a sprint. The talk did not lose material, it lost the room's ability to absorb the ending.

2. Slide-side underuse, no antipattern ID, and the biggest structural finding here. Nine of twelve slides never got a spoken counterpart, and the four one-line verdict slides ('Let's build a REAL agent', 'Both apps, built from the same tiles.', 'No loser framework. Both win.', 'THE WINNER IS THE JAVA DEVELOPER.') contain sentences that were never said out loud. The deck's whole thesis exists only in pixels. The close voiced a chant instead ('let's take hands together and say Java wins ... No? No? No, not doing this anymore'), which the speaker has confirmed is a deliberate flop gag - but it means the talk's actual verdict was never delivered in any channel. Saying slide 11 aloud costs four seconds.

3. Round structure ran silently. 'Round' appears twice in 48 minutes; rounds 2 and 3 are never named. The deck builds a breadcrumb, four dividers and a roadmap, and the narration never once uses them, so section boundaries get negotiated mid-sentence instead of announced.

4. `going-meta` (severity: info) - AV narration in the first ninety seconds ('Why do we hear echo? Not our fault. Computer?', 'It's a little bit dark', 'Can we do a little bit lights', 'for some reasons it's not running full screen'), plus 'we have a joke about agents that no one gets' and 'you just destroyed all magic. People thinking that we're smart'. Individually most of these are converted into comedy, which is why this is info rather than warning, but the opening block is dead time before any content.

5. `alienating-artifact` (severity: info) - the J.Lo pun landed ('That's a perfect crowd because this joke never landed in Europe'), but the 'Jenny from the block' extension runs 32:28 to 36:35 and is explicitly millennial-gated ('as my millennial friend will explain to you now'). The repeated 'No one usually ask who the hell is Jenny, right? No one ask who the hell is Jenny, right?' is a joke fishing for a response it did not get. The Scala 'Oh my god. Get out' is affectionate and instantly retracted.

6. Underuse - `retrieval-beat` and `new-bliss`, both free. Every callback is self-answered inside the same breath ('And you remember what it does? It gets the calendar and it gets the deals'), so the room never has to produce anything after the opening polls. And a talk whose deck literally ends on 'THE WINNER IS THE JAVA DEVELOPER' has no future-state close at all - it ends on housekeeping about API keys.

7. Underuse - `traveling-highlights` / `crawling-code` / `emergence`. Roughly forty minutes of live IDE and terminal with no built-in highlighting; emphasis is handled by ad-hoc zooming ('let me make it as large as possible here', 'let me get a little larger'). The agentic-flow diagram is narrated node by node but is explicitly static ('My diagram was static'), so the one place a progressive reveal was already half-built was left flat.

Not firing, worth recording: `dead-demo` did NOT recur despite genuine friction (echo, dark screen, font size, wrong directory) - every demo stayed problem-framed and resolved. `hiccup-words` did NOT recur (1.41 percent, this family's cleanest). `negative-ignorance` did not fire; all polls are positively framed.
